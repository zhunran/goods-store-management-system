# 商品商城管理系统 — 业务状况

> 文档状态：项目完成态描述（预设完成视角，运行态收口项于交付前完成）。

## 一、项目定位

- 项目名称：goods-store-management-system-parent（商品商城管理系统）
- 业务形态：B2C 商城，面向**会员/用户**的商品交易平台 + 面向**管理员**的后台管理
- 技术形态：Spring Cloud Alibaba 微服务架构，后端 6 大业务服务全部编译通过、无异常，中间件连接正常，Nacos 可发现全部服务

## 二、业务域概览

系统按业务拆分为 6 个核心域：

### 1. 认证域（goods-store-auth-api，8083）

- 用户注册、登录、刷新令牌、修改密码（AuthController）
- 管理员登录（AdminAuthController）
- 双令牌 JWT（access 30min + refresh 7天，refresh 存 Redis 7 天用于无感续期）
- JWT 密钥通过环境变量 `JWT_SECRET` 注入（含固定默认值），并有网关与 auth-api 两处一致、重启不漂移的约定，避免服务重启导致用户被迫重新登录
- RBAC 权限模型：用户 / 管理员、角色、权限、角色-权限、管理员-角色 五类实体
- 管理员初始数据自动初始化（AdminDataInitializer）
- 密码加密存储

### 2. 品牌域（goods-store-brand-api，8081）

- 品牌 CRUD、分页查询、上/下架状态管理
- 品牌图片上传（本地文件存储 FileUploadUtil / LocalFileUploadUtil）

### 3. 商品域（goods-store-product-api，8084）

- 商品（Good）CRUD、分页查询、上/下架
- 商品分类（Category）树形结构
- 商品 SKU（ProductSkuEntity）、商品详情图（GoodDetailPicsEntity）
- 规格组 / 规格项（SpecGroupEntity / SpecItemEntity）
- 依赖品牌服务（Feign 调用，含降级 FallbackFactory）

### 4. 会员域（goods-store-member-api，8085）

- 会员信息查询 / 更新 / 分页
- 收货地址管理（MemberAddress）
- 敏感信息脱敏（DesensitizeUtil）
- 当前登录用户上下文（CurrentUserUtil）

### 5. 交易域（goods-store-trade-api，8086）

- 购物车（Cart）增删改查
- 订单（Order）创建、查询、取消、状态流转（OrderStatus）
- 订单项（OrderItem）
- 下单 / 取消通过 RabbitMQ 消息异步处理（OrderMessageProducer / OrderCreateConsumer / OrderCancelConsumer）
- Redisson 分布式锁防重复下单
- 依赖会员服务、商品服务（Feign，含请求头透传 TradeFeignHeaderInterceptor）

### 6. 秒杀域（goods-store-seckill-api，8087）

- 秒杀活动（SeckillActivity）管理
- 秒杀商品（SeckillGood）与库存预热（StockPreheatJob）
- 秒杀订单（SeckillOrder / SeckillOrderItem）创建与消费
- Redis 预扣库存 + Redisson 分布式锁 + RabbitMQ 异步下单（SeckillMqConfig / SeckillMessageProducer / SeckillOrderConsumer）
- 依赖商品服务、会员服务（Feign）

## 三、业务调用关系

- 前端（管理端 / 用户端）统一经**网关**进入，再路由到 **BFF 聚合层（goods-store-web）** 或各业务服务
- 服务间通过 **OpenFeign + SPI 契约接口**调用：
  - product → brand（商品读取品牌信息）
  - trade → member、product（下单时校验会员与商品）
  - seckill → product、member（秒杀库存与会员）
- BFF 层聚合多个服务的接口，为前端提供统一的 `/app/api/**` 入口
