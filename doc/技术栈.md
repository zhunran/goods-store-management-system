| 分类 | 技术 | 版本 |
| --- | --- | --- |
| 语言 | Java | 25 |

| 分类 | 技术 | 版本 |

| 基础框架 | Spring Boot | 4.1.1 |

| 微服务 | Spring Cloud Alibaba | 2025.1.0.0 |

| 监控 | Actuator | 随 Boot 管理 |
| JSON | Jackson 3（tools.jackson） | 随 Boot 管理 |

## 四、可观测性

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| SkyWalking | 9.7.0 | Java Agent + OAP + UI，OAP 存储已切换为 MySQL（goods_store 库） |
| 日志 | Logback / Log4j2 | 各服务 metrics 日志输出至 `logs/` |

## 五、关键版本说明

- Spring Boot 4.x + Spring Cloud 2025.x + SCA 2025.x 为当前较新的版本组合，需注意：
  - 网关路由配置已迁移至 `spring.cloud.gateway.server.webflux.routes`
  - Druid 使用核心包 + 手动注册 DataSource（Boot 4 下 druid-spring-boot-3-starter 自动装配不兼容）
  - MyBatis-Plus 分页插件需单独引入 `mybatis-plus-jsqlparser`
  - Lombok 在 JDK 25 下需显式配置 annotationProcessorPaths
- 微服务各模块通过父 POM 的 `dependencyManagement` 统一版本管理
