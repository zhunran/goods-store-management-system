## 四、可观测性

| 组件       | 版本                    | 说明                                                  |
| ---------- | ----------------------- | ----------------------------------------------------- |
| SkyWalking | 9.7.0                   | Java Agent + OAP + UI，8 个服务全量挂载（零代码侵入） |
| OAP 存储   | MySQL（goods_store 库） | 建表规则「模型名\_yyyyMMdd」，按天滚动，约 60 张/天   |
| 日志       | Logback / Log4j2        | 各服务 metrics 日志输出至 `logs/`                     |

接入状态（2026-09-05 实测通过）：

- 8 个服务（gateway / web / auth / brand / product / member / trade / seckill）以 `-javaagent` 三参数挂载，gRPC 上报 127.0.0.1:11800，UI 端口 8091。
- 已验证：服务拓扑（含 DB 虚拟节点）、跨服务 Trace（sw8 传播，单链 4 服务 46 Span）、SQL 观测（MyBatis / MySQL JDBC / Druid）、错误追踪（is_error + 异常堆栈事件）。
- 运行约束：OAP 需 JDK 17 启动（`skywalking/apache-skywalking-apm-bin/bin/oapService.bat`）；Spring Framework 7 下 spring-mvc / webflux / gateway 插件 witness 失活，入口 Span 由 Tomcat 插件接管（URL 命名降级），sw8 传播不受影响。
- 计划与实测结论详见 `doc/schedule/stage-4-plan/skywalking-integration-plan.md`（含第九节实施结果回写）。

## 五、关键版本说明

- Spring Boot 4.x + Spring Cloud 2025.x + SCA 2025.x 为当前较新的版本组合，需注意：
  - 网关路由配置已迁移至 `spring.cloud.gateway.server.webflux.routes`
  - Druid 使用核心包 + 手动注册 DataSource（Boot 4 下 druid-spring-boot-3-starter 自动装配不兼容）
  - MyBatis-Plus 分页插件需单独引入 `mybatis-plus-jsqlparser`
  - Lombok 在 JDK 25 下需显式配置 annotationProcessorPaths
- 微服务各模块通过父 POM 的 `dependencyManagement` 统一版本管理
- JWT 签名密钥经环境变量 `JWT_SECRET` 注入（各服务带固定默认值兜底），网关与 auth-api 保持一致；密钥需 ≥32 字节，且不应在服务重启间变更，否则已签发的 access/refresh token 将全部验签失败
